# 麦麦派对策划师（mcd-party-planner）

一个基于**麦当劳中国 MCP** 的 WorkBuddy Skill：把"家长想给娃办一场麦当劳主题派对/生日会"从一句模糊的愿望，一路托管到**真实下单**，并自动生成当日纪念。

不是演示脚本——全流程（选主题 → 选门店 → 定日期场次 → 收名单 → 定制餐品 → 真实落单 → 纪念徽章）均已用真实麦当劳 MCP 数据跑通，派对订单为真实付费订单。

## 它解决什么问题

办一场小朋友的派对，难点从来不是"订个场地"，而是琐碎的协调：谁家娃来、几岁、有没有过敏、想吃啥、加购什么、人数够不够成团——这些靠家长在微信群里接龙、手动统计，又慢又容易错。

这个 Skill 把这段协调工作整体接管：名单数据驱动，所有决策数据（人数/忌口/年龄/想吃的）来自一次收集，**不回头在对话里逐项问**；主办人只需要做主观选择（主题/门店/时段）。

## 核心能力

- **双模名单收集**（发起时自选）：
  - 腾讯问卷：一次建好含全部题目的报名问卷（描述自带餐厅地址），自动发布，发家长群各家自填，读回自动汇总；
  - 聊天框：家长群接龙直接粘贴，LLM 解析成结构化名单。
- **智能定制餐品**：按每个小孩的年龄 + 想吃的 + 忌口，确定派对内含开心乐园餐的具体选项（按过敏原剔除冲突项），并生成额外加购清单（不重复收费）。
- **加购省钱**：下单前查当前门店可用券与卡包券，有券直接推荐；同品多规格按性价比推荐。
- **真实落单**：派对订单 `party-order-create` + 加购 `create-order`，均为真实付费，执行前完整复述、需主办人明说"创建订单"。
- **当日纪念**：落单成功自动生成纪念徽章 + 拍立得相框（日期用派对当日），纯本地绘制，零 API 成本。
- **日常带娃场景**：找附近门店 + 预约时段；门店有无儿童乐园靠"用户标记 + 本地记忆"，不编数据。

## 快速开始

### 依赖

| 依赖 | 何时需要 | 安装/授权 |
|:---|:---|:---|
| 麦当劳 MCP（`mcp.mcd.cn`） | 必需 | https://open.mcd.cn/mcp 登录领 Token → WorkBuddy 连接器 → 自定义连接器填地址 + `Authorization: Bearer <Token>` → 保存并信任；或写入 `~/.workbuddy/mcp.json` |
| 腾讯问卷连接器 | 仅问卷模式 | 连接器 → 腾讯问卷 → 扫码授权；不可用时 Skill 自动降级为聊天框模式 |

复制 `.env.example` 为 `.env` 填入真实 Token（`.env` 已被 `.gitignore` 忽略，不会进仓库）。

### 使用

装进 WorkBuddy 后，对话里直接说，例如：

> 用麦麦派对策划师，给娃办个麦当劳生日派对

Skill 会先收集主办人的想法（城市/区域、时间想法、主题预算倾向、规模感），已提供的信息不重复问；随后用真实数据核验可约门店/日期/场次，流程内不写死任何场景参数。

## 一次真实全流程实跑（2026-10-25）

北京朝阳 / 万圣节窗口 / 疯狂动物城主题 / 5 位小朋友：

1. `now-time-info` 校准万圣节窗口 → 选定 10-31 周六晚场 18:30–20:00；
2. 门店清单（店名+地址+距离+营业状态）由主办人逐家选定朝阳公园南路得来速店；
3. 腾讯问卷报名表回收 6 份 → 汇总实到 5 人、忌口清单（1 例海鲜过敏）、年龄分布、餐品统计；
4. 加购前查券并按特惠价推荐，含税合计 ¥334.4；
5. 派对主单真实落单成功（¥290，待支付），加购单按系统限制改到派对当天；
6. 落单后生成当日纪念徽章 + 相框。

跑通后沉淀的一手事实（写回 SKILL.md）：问卷建完必须显式发布、派对订单无主食变体参数（内含餐当天现场选）、到店自取不支持提前预约等。
